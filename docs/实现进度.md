# 实现进度

当前已实现 Hub、Windows 执行端、Hermes MCP、可信来源、原生跟进、输入附件与原聊天发送。本文只记录可公开的功能进度，不记录维护者或部署用户的主机、账号、目录与会话。证明范围见[验收记录](验收记录.md)。

## 已完成

- 本机 app-server 握手、并发请求、通知/审批分流、超时、进程退出和 Windows owned 进程树清理。
- 按 UID、用户、profile、执行端和可信来源路由；任务、操作、事件及收据持久化。
- 创建与继续同一会话、历史、运行中追加、Goal 及暂停/停止静止核对。
- 原生 runs 跟进、调用前 API session 绑定、遗漏补查和累计恢复预算；未知写保持原收据，不盲目重做。
- 输入附件私下绑定与传输、授权目录浏览、文本和二进制读取、产物自动获取和补取。
- 官方发送函数、固定原聊天目标、私有只读快照、持久发送尝试及不确定结果去重。
- 多授权文件夹、固定任务子目录、路径与链接限制、兄弟并行及父子冲突；协议 2 拒绝旧执行端。
- 普通用户隐藏登录自启、持久配对与协调更新；真实部署参数由使用者提供。

## 已有验证

Windows 全量 Go 测试、go vet、双平台构建，以及隔离 Linux race 与完整 Python 测试通过。公开接口测试覆盖目录、文件、恢复与来源隔离；真实 Codex、跨机器文件和 Hermes 模型核验已有记录。不同测试类型的边界保留，不把 fixture 当作真实微信。

## 尚需现场验收

第二名真实用户和第二台执行电脑、真人微信批准/拒绝、实际微信附件收发、长期运行与故障观察。桌面已有活跃聊天接管另行验证；连接或初始化成功不表示模型一定可执行。
