## 第一轮：本机 app-server 接口

范围为独立 app-server 进程与 stdio 通信，以及不启动模型的本机探测。该轮只是方案阶段一的本机接口部分，不表示阶段一或首版 R01—R13 已完成。

分工：测试 agent 在公开接口逐条建立失败测试，实现 agent 按测试补齐客户端，资料 agent 核对本机 schema，主 agent 集成探测命令。实现后分别审查代码约定与需求符合性。

公开接口位于 `internal/executor`：`Start` 管理独立进程及初始化；`Call` 发起一次请求；`Events` 提供通知和服务端请求；`Respond` 回答有效请求；`Done`、`Err` 和 `Close` 提供终止状态与清理。上层尚未实现用户授权与审批决策，不能将 `Respond` 直接暴露为远程审批工具。

本机核对版本为 Go 1.27.3、Codex CLI 0.163.0。官方接口依据为 [app-server Protocol](https://learn.chatgpt.com/docs/app-server#protocol) 与 [Initialization](https://learn.chatgpt.com/docs/app-server#initialization)，并与本机 `generate-json-schema` 输出核对。schema 导出成功本身不代表运行验收通过。

已确认的协议约定：

- stdio 使用逐行 JSON，消息不带 `jsonrpc` 字段。`initialize` 成功后发送 `initialized`，再执行其他调用。
- 服务端请求与客户端响应分开处理。请求 ID 支持整数和字符串，数字 `1` 与字符串 `"1"` 不能合并。
- `serverRequest/resolved` 使用 `requestId` 和 `threadId`。对应请求已解决后，不能再次回答。
- 请求超时不证明远端没有执行。客户端不自动重发请求，不提供持久幂等或断线重放保证。
- `Respond` 写出成功不代表审批动作已经执行或任务已经完成；后续业务层仍须核对原生状态。
- `account/read` 显式传入 `refreshToken:false`。探测仅输出账户是否配置，不输出邮箱、账户路由或认证材料。
- 若后续增加只读历史探测，`thread/list` 应传 `useStateDbOnly:true`；本机 schema 表明默认路径可能扫描并修复历史元数据。
- 本轮初始化不启用 `experimentalApi`。消息分流测试不代表实验性 Goal、结构化问题或其他原生业务接口已通过。

真实探测另有一条现有配置告警：Codex 0.163.0 不识别 `disable_response_storage`。这不阻止本次探测，未修改用户配置。正常 stdin 关闭链路已通过；必须强杀时，当前实现只处理直接子进程，尚未证明能强杀 Scoop shim 的全部后代。

测试实际发现并修复了并发阻塞、已解决请求仍可回答、等价 JSON 转义 ID 匹配失败、管道写入不受截止时间限制、强杀被错误报告为正常退出等问题。写入中取消会结束连接，不能据此推断请求没有执行。事件队列溢出会明确报错；没有持久事件重放能力。

审批回归测试通过 loopback 控制连接和管道首字节信号固定时序：验证取消后仍能有效回复原请求，以及对端确实没有收到已失效的旧回复。初始化拒绝测试同时保留原 RPC 错误与强杀清理错误，不再只返回前者。

尚未验证真实模型回合、真实审批与问题、Goal、桌面已有活跃聊天、远端 Hermes、微信或跨用户隔离。

## 运行本轮检查

在项目根目录使用 PowerShell。当前工具环境缺少默认 Go 缓存目录，下面仅为本命令设置缓存，不修改用户全局配置。

```powershell
$env:GOCACHE = Join-Path ([System.IO.Path]::GetTempPath()) 'dots-duet-lite-go-cache'
go test ./... -count=1
go vet ./...
go build -o dist/executor.exe ./cmd/executor
.\dist\executor.exe -probe -timeout 15s
```

`-probe` 启动新的本机 app-server，完成初始化并读取账户配置，然后退出。`accountConfigured:true` 只代表配置存在；`inferenceVerified:false` 明确表示没有验证模型访问；`desktopChatAttached:false` 表示没有接管桌面聊天。Hub 入口仍为占位，不能用该探测启动远程任务。
