# 验收记录

本文件公开验证范围及未覆盖项，不保存部署用户、主机、来源、会话或私有路径。实际部署参数另存私有记录，可参照[部署记录模板](部署记录模板.md)。协议替身、官方网络发送器 fixture 与真实模型分别标明，不互相代替。

## 当前范围

Hub、Windows 执行端、Hermes MCP、可信来源插件、原生 runs 跟进、输入附件和原聊天交付均已有实现。已有真实 Codex 执行、跨机器取文件与 Hermes 模型核验记录。第二名真实用户与第二台执行电脑、真人微信审批和实际微信附件收发仍需现场验收。

## 已验证行为

| 接口或行为 | 已有证据与边界 |
| --- | --- |
| Go 测试与静态检查 | Windows 全量测试、go vet 与双平台构建通过。普通测试使用独立 stdio 协议进程，不调用模型。 |
| Linux 并发 | 隔离无特权环境的完整 race 测试通过。设置 GORACE=atexit_sleep_ms=0 避免测试 peer 的 race 退出附加等待与一秒关闭期限冲突，不改变生产期限。 |
| Python 适配 | Linux 完整 30 项通过，无跳过；Windows 的 Unix 接口测试跳过，结果独立记录。 |
| 真实 Codex | 临时工作区生成固定内容，下载核对后重建进程，并继续同一原生会话核验。独立 app-server 不代表接管桌面已有活跃聊天。 |
| 跨机器文件 | 实际 Codex 生成文本和二进制，Hub/worker 获取并核对私有副本，主动补取与同操作去重通过。来源为显式 fixture，不证明微信送达。 |
| UID 和可信来源 | 实际业务 UID 经 Unix socket/MCP 查询通过；未绑定来源、参数替换、伪造 HTTP 身份与跨 UID 操作拒绝。 |
| 文件夹与工作目录 | 组合公开接口验证指定已有子目录、附件与产物不误写父目录；越界、缺失目录、后续换目录、运行期替换、恢复改根均拒绝。兄弟目录可并行，父子目录互斥。 |
| 协议兼容 | 版本 2 的 WebSocket 握手拒绝不支持工作目录的旧执行端，双端需协调升级。 |
| 原生 runs | 同幂等键返回原 run，API 重建后可查询；失败运行的新诊断保留旧 request/session/key，不重做原 Codex 工作。 |
| Hermes 模型核验 | 实际模型通过 MCP 和来源插件查询会话、Goal、文本并记录核验；原生 notLoaded 和 goal=null 分别处理，不推断为空闲。 |
| API 范围 | 后台 API session 只可查询预绑定任务；原任务跟进可读，全局枚举和其他任务拒绝。 |
| 恢复与停止 | 原生重启、旧审批失效、未知写不重放、暂停版本和未决写竞争已检查；同属服务账号的失效 socket 可恢复，活跃 socket 不替换。 |
| 输入附件 | 当前已授权消息绑定私有字节；二进制与空文件在启动前落地。prepare 不写文件，重复 operation 不重写，公开响应不含附件 Base64。 |
| 官方发送边界 | 官方发送函数与外部网络 fixture 核对实际字节和目标；使用私有只读快照。超时、部分及不足回执保持 unknown，不盲目重发。未证明真实微信网络送达。 |
| 隔离与后台运行 | 无特权服务、私有目录、跨账号拒绝、公共程序不可写、隐藏登录启动、单实例及实际连接均已有现场检查。各部署仍须自行验收，示例不授予权限。 |

## R01—R13 与现场缺口

| 要求 | 当前实现 | 仍需现场确认 |
| --- | --- | --- |
| R01 路由 | UID、scope、来源和 API 任务绑定 | 两名真实用户与两台电脑交错使用 |
| R02 就绪 | 连接、初始化、目录分别报告 | 长时间断网、账号路由及进程故障 |
| R03 目录 | 多授权根与固定任务子目录 | 各用户实际授权清单 |
| R04 会话 | 创建、继续、历史、Goal 占用 | 多电脑各多会话；桌面活跃聊天不在已证范围 |
| R05 列表 | SQLite 持久任务和归属 | 实际聊天切换及持续使用 |
| R06 停止 | 精确回合、暂停与静止核对 | 真实长回合的追加、停止竞争 |
| R07 审批 | 结构化问题与单项人工确认 | 真人批准/拒绝与渠道确认能力 |
| R08 通知 | 持久事件、去重、原聊天 outbox | 真实目标聊天的低打扰送达 |
| R09 文件 | 输入、读、自动/主动下载与发送边界 | 真实微信附件输入和输出 |
| R10 核验 | 执行、核验、获取、交付分开 | 实际微信媒体回执 |
| R11 恢复 | 原收据、累计预算、未知写核对 | 连续运行与更广故障矩阵 |
| R12 隔离 | 不改 Hermes 核心、独立 UID | 各环境实际账号和目录权限 |
| R13 跟进 | 原生 runs、补查、诊断与恢复预算 | 生产持续运行 |

## 审查与证据边界

公开接口 RED→GREEN 曾定位并修复事件保存失败后继续执行、API 查询越界、失败终态反复轮询、未决写提前释放和发送前文件替换等问题。文件夹切片的 Standards 与 Spec 独立审查均无遗留发现。

真实模型组合链路与不同上游版本的契约检查分别记录，不把后续无模型复验改称完整模型流程重跑。初始化、工具发现、私有副本或模型自报均不能证明业务完成或微信送达。真实原始记录不进入公开仓库。
