# 部署记录模板

本模板只含占位项。真实主机、IP、维护账号、UID、私钥路径、工作目录、聊天来源和会话标识仅记录在仓库外的私有位置，或被忽略的 `deployments.local/`。私钥、token 和认证正文不写入记录；只记私有文件的存放位置。

## 目标与范围

- 部署时间、操作类型与获准范围：待填写。
- 代码版本、依赖锁及双端程序 SHA-256：待填写。
- 服务器与执行电脑、目标 Hermes profile：私下填写。
- 本机与服务器程序、状态、日志和 socket 位置：私下填写。
- 授权根及 folder ID 映射、工作目录约束：私下填写。

## 配对和运行

记录 scope、凭据文件位置与可信来源的核对方式，不公开身份值。更新保留原 token、数据库和任务编号；正常重启自动复连。

分别记录 Hub、网关、MCP、worker、执行端的服务名、实际账号、自启方式和启停方法。Windows 默认普通用户登录后隐藏运行；未实际重启或登录测试时写明限制。

## 验收

| 检查 | 结果与证据位置 |
| --- | --- |
| 服务、实际 UID/权限、单实例、自启和日志 | 待填写 |
| 认证连接、Codex 初始化、账号检查 | 待填写 |
| 授权根、子目录、未授权与越界拒绝 | 待填写 |
| 插件三 hook、MCP 七工具与工作目录字段 | 待填写 |
| 原生 API 持久幂等与 worker | 待填写 |
| 经单独授权的真实模型、人工审批和微信收发 | 未验证，或填写实际结果 |

分别标明已通过、失败、未验证。管理员 audit、fixture、真实聊天和真实模型不互相代替。

## 更新与恢复

记录切换前活动任务/队列检查、私有一致性备份、双端停启顺序、版本兼容与回滚条件。升级后有新业务写入时先核对事实，不直接覆盖旧数据库。记录临时文件清理和保留的回滚材料。
